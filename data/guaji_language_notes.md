# Guaji Language Notes

Internal working notes on how the Guaji language diverges from its Taino/Arawak base over ~2000 years of isolation on Adonia.

## Starting point

- Base language: Taino/Arawak (used as inspiration only — Guajicutea is on Adonia, not Earth)
- Isolation: ~2000 years on a single volcanic island
- Writing system: **Bikumaku** — logographic script adopted from Tapuyan mainland (~315 CE earliest tablets), adapted to Guaji language. Specialist priestly use only. See `guaji_writing_system_notes.md` for full details.
- Two-tribe split (Yukurí/Caracurí) for 750–1000 years, then merger in 516 CE

## Phonology — sound changes from base Taino

### Vowel system
- Base Taino likely had 5 vowels: /a e i o u/
- Guaji collapses to 3 vowels: /a i u/
  - /e/ → /i/ (raising)
  - /o/ → /u/ (raising)
- Result: Guaji sounds tighter, more percussive than Taino
- Already reflected in invented words: makú, Yukumá, Yukurí — heavy /u/ presence

### Consonant changes
- **Initial /p/ → /b/**: voicing of stops word-initially (common lenition)
- **Intervocalic /d/ → /r/**: flapping/lenition between vowels
  - Already visible in names ending in -rí (Yukurí, Caracurí, Guanarí, Trogoní, Vienturí)
- **/k/ before /i/ → /s/ or /ts/**: palatalization
- **Glottal stop /ʔ/ emerges** as phoneme: from vowel sequences and word-final vowels
  - Guaji would have a glottal catch that base Taino didn't
  - Probably not written in our romanization but affects rhythm

### What this means for naming
- Guaji words favor: /a i u/ vowels, /b g k m n r t y w/ consonants
- CV syllable structure mostly preserved from Taino
- Final vowels common (words end in vowels, not consonants)
- /r/ much more common than in base Taino (from /d/ lenition)

## Morphology — productive suffixes

These probably started as free particles in proto-Taino and fused into suffixes during the isolation period (grammaticalization).

- **-í** = place of / people of
  - Yukurí (mountain people), Caracurí (sea people), Guanarí (golden hill place), Trogoní (trogon place), Vienturí (wind place)
- **-á** = great / mountain feature / augmentative
  - Yukumá (great mountain), possibly from yuku (mountain) + -á (augmentative)
- **-uma** = place of extraction / digging
  - Yaruma (mine) — possibly yaru (to dig/extract) + ma (place)
- **-bara** = flow / movement of
  - Yukubara (mountain-flow) — yuku (mountain) + bara (flow)

### Compound structure
- Guaji compounds are head-final: modifier + head
- yuku (mountain) + bara (flow) = yukubara (mountain-flow)
- guani (gold) + arí (place) = Guanarí (golden hill)
- vientu (wind) + arí (place) = Vienturí (wind place)

## Vocabulary — new semantic fields

These domains either don't exist in base Taino or are far more developed in Guaji due to the volcanic island environment:

### 1. Volcanic terminology
Base Taino had some volcanic vocabulary (Caribbean islands are volcanic), but Guajicutea's active volcano and the yukubara event required a much richer set:

| Guaji term | Meaning | Etymology |
|-----------|---------|-----------|
| yukubara | volcanic mudflow | yuku (mountain) + bara (flow) — divine judgment |
| yuku | mountain | base root |
| yukumá | great mountain / sacred volcano | yuku + -má (augmentative) |
| yukubúka | eruption (explosive) | yuku + buka (burst/open) |
| yukukura | lava flow (burning stone) | yuku + kura (burn/heat) |
| kuri | volcanic ash | root — gray dust |
| bukuti | sulfur vent / fumarole | buku (breath) + -ti (place) |

Key distinction: yukubara = the mountain flows mud, yukukura = the mountain flows fire, yukubúka = the mountain bursts open. Three behaviors of the same being.

### 2. Mining vocabulary
Taino collected gold casually from streams but didn't mine. Guaji developed organized mining at Mina Yaruma:

| Guaji term | Meaning | Etymology |
|-----------|---------|-----------|
| yaruma | mine / digging place | yaru (dig) + ma (place) |
| guani | gold | root |
| wariku | to pan (wash sediment) | root — to wash/sift |
| takutaba | hammerstone | taku (strike) + taba (stone) |
| guanibiti | gold vein | guani (gold) + biti (thread/line) |
| guanikuri | gold-bearing gravel | guani + kuri (small stones) |
| mukutaba | grinding mortar | muku (grind) + taba (stone) |

### 3. Calendar / timekeeping
Taino had lunar months, but Guaji developed a formalized calendar with carved records:

| Guaji term | Meaning | Etymology |
|-----------|---------|-----------|
| waku | year / cycle | root — turn/return |
| warí | moon / month | root — moon |
| warí yabí | hidden month (intercalary) | warí + yabí (hidden) |
| maku | tally / count / mark | root — mark |
| bikú | carved circle (year mark) | root — circle |
| bikumá | great ring (decadal mark) | bikú + -má (augmentative) |

### 4. Storm classification
The storm ledger implies precise vocabulary for storm types:

| Guaji term | Meaning | Etymology |
|-----------|---------|-----------|
| bari | ordinary storm | root — wind/rain |
| wirá | hurricane | from proto-Taino *hurakan, sound-shifted: h→w, u→i, final -n lost |
| wirayú | killing hurricane | wirá + yú (death) |
| kawa | sea / ocean | root (cf. cara- in Caracurí) |
| kawa yabí | still sea (calm period) | kawa + yabí (hidden/still) |
| vientu waku | trade wind (returning wind) | vientu + waku (cycle) |

### 4a. Storm ledger marks
The pictographic notation system used in the catacomb calendar corridor:

| Guaji term | Meaning | Etymology |
|-----------|---------|-----------|
| barimaku | wave-mark (ordinary storm) | bari + maku (mark) |
| wirabikú | hurricane-spiral (major hurricane) | wirá + bikú (circle/spiral) |
| yabirí | crossed-dead (deaths) | yabí (lost) + -rí (those who are gone) |
| kanuabúka | broken-canoe (fleet/village loss) | kanua (canoe) + buka (broken) |
| yukumaku | mountain-mark (storm + landslide) | yuku + maku |
| buramaku | red handprint (recorder's mark) | bura (red) + maku |

### 5. Catacomb / cave architecture
Taino used caves ritually but didn't carve them:

| Guaji term | Meaning | Etymology |
|-----------|---------|-----------|
| bikabá | corridor / passageway | bika (walk) + ba (path) |
| kurubá | burial niche | kuru (rest) + ba (place) |
| wakubá | carved chamber | waku (open space) + ba (place) |
| tabamaku | stone-carving (the act) | taba (stone) + maku (mark) |

## Dialectal layer — Yukurí vs Caracurí

### Pre-516 CE split
750–1000 years of separation on the same island produced real dialectal divergence:

**Yukurí (western/mountain dialect):**
- More conservative phonologically — mountain communities preserve older forms
- Richer volcanic and highland vocabulary
- May preserve sounds that Caracurí dropped (e.g., older consonant clusters)
- More words for cave, highland, and volcanic features
- Less contact with other islands → fewer loanwords

**Caracurí (eastern/sea dialect):**
- More innovative phonologically — coastal trade communities change faster
- Richer maritime and trade vocabulary
- More loanwords from other Adonian languages (trade contacts)
- May have innovated the glottal stop and vowel reduction first
- More words for sea states, winds, navigation, trade goods

### Post-516 CE merger
- Caracurí form became dominant (Caracurí absorbed Yukurí)
- But Yukurí vocabulary survived in specific domains: volcanic terms, mining terms, highland ecology, cave/catacomb terminology
- Result: **stratified lexicon** — Caracurí base with Yukurí specialist terms layered in
- Similar to how English has Germanic base words with French/Latin specialist vocabulary
- The word "yukubara" itself is likely Caracurí (stated in article) — the Caracurí name for the event became dominant
- But "yuku" (mountain) as a root is probably Yukurí — it's a mountain word that the sea people adopted

### Naming conventions after unification
- People names: Caracurí forms preferred
- Place names in highlands: often preserve Yukurí forms
- Place names on coasts: Caracurí forms
- Technical terms (volcanic, mining, cave): often Yukurí roots with Caracurí morphology

## Adonia geography (for context)

- **Planet**: Adonia
- **Sea**: Capuyaquiran Sea
- **Greater Capuyaquiran**: eastern archipelago
- **Lesser Capuyaquiran**: western archipelago
- **Guajicutea**: largest island, in the Greater Capuyaquiran (east)
- **Mainland near Tapuya**: source of wool/camelid fiber, beyond the Lesser Capuyaquiran (west)
- Settlers arrived from the west (Lesser Capuyaquiran / mainland)
- Transit trade: canoes traveling between Lesser (west) and Greater (east) stop at Guajicutea to resupply
