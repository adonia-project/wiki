## Naming Patterns

- **Full name format**: [First name] [Last name]
- **Compound first names are NOT common** — names like "Cabdulqaadir" or "Cabdiraxmaan" are NOT standard Burawi naming. The "Cabdi/Cabdul" prefix convention is from a different naming tradition not native to Burawa.
- **Common combinations**: Catholic first name + professional last name (e.g., Markus Xirsi, Luqas Xasan, Antoni Cabdalle)
- **Less common**: Historic Burawi first name + professional last name (e.g., Dhuxul Xaaji, Shiire Shire)
- **Prestige**: Historic Burawi first name + clan last name (e.g., Xirsi Xirgo, Dhane Badal)

## Notes for Article Creation

- Avoid "Maxamed" and "Maxamuud" as names — these are very rare in Burawa
- Avoid compound "Cabdi-" prefixed names (Cabdulqaadir, Cabdiraxmaan, etc.) — these are NOT Burawi naming conventions
- Use x for /ħ/, c for /ʕ/, q for /q/, dh for /ɖ/ per Burawi orthography
- The "/" abbreviation (C/qaadir, etc.) is NOT a Burawi convention — do not use it
