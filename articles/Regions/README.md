# Regions

Geographic and cultural regions. Each should have its own folder:

```
Regions/
└── [Region_Name]/
    ├── Laws/
    ├── Regions/  # Sub-regions if applicable
    ├── Events/
    ├── Customs/
    ├── Economy/
    └── .gitkeep
```

## Subfolder Purpose

- **Laws/** - Regional laws and regulations
- **Regions/** - Sub-regions or smaller geographic divisions
- **Events/** - Events specific to the region
- **Customs/** - Regional cultural practices
- **Economy/** - Regional economic information
