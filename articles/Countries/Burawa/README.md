# Burawa Wiki Articles

This folder contains all wiki articles related to Burawa, organized by category.

## Structure

- **History/** - Historical periods and eras (Prehistoric, Ancient, Medieval, Colonial, Modern)
- **Places/** - Cities, rural administrations, geographic features, lakes, mountains
- **People/** - Notable Burawi people and groups
- **Politics/** - Elections, political parties, government acts
- **Economy/** - Economic systems, housing, labor
- **Infrastructure/** - High-speed rail, transportation
- **Concepts/** - Cultural traditions, languages, geographic concepts
- **Events/** - Wars, battles, historical events

- `Burawa.mediawiki` - Main country article
