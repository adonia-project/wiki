# Countries

Each country should have its own folder with the following subfolders:

```
Countries/
└── [Country_Name]/
    ├── Laws/
    ├── Regions/
    ├── Events/
    ├── Customs/
    ├── Economy/
    └── .gitkeep
```

## Subfolder Purpose

- **Laws/** - Legal documents, acts, constitutions
- **Regions/** - Administrative regions, provinces, states
- **Events/** - Historical events specific to the country
- **Customs/** - Cultural practices, traditions
- **Economy/** - Economic articles, industries, trade
