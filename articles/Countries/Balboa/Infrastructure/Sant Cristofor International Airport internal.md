# Sant Cristòfor International Airport — Internal Notes

## Key Facts
- **IATA**: SCI (main), ARZ (Terminal D / Areza services)
- **ICAO**: SCIB (main), SCAR (Terminal D)
- **Location**: Sant Martí ciutat, eastern Sant Cristòfor
- **Opened**: 15 March 1985
- **Passengers**: ~35M (2025)
- **Cargo**: 612,000 tonnes (2025)
- **Aircraft movements**: 287,400 (2025)
- **Elevation**: 9m / 28ft
- **Runways**: 2 (09/27: 3,200m, 15/33: 2,600m)
- **Terminals**: 4 (A domestic, B Abyala/Lurandia, C Kaftia/Illypnia/Fosia, D Areza)
- **Hubs**: Balboa Airlines (flag), RapidAir (LCC)
- **Owner/operator**: Balboa Airports Authority

## Terminal History
1. **1985**: Opens with Terminal A (domestic) + Terminal B (international, Abyala/Lurandia)
2. **2000**: Terminal D opens — AC-funded, separate building, ARZ code, Areza customs
3. **2003**: Areza International Airport closes; Line 9 opens connecting airport to Areza
4. **2008**: Terminal C opens — new international for Kaftia/Illypnia/Fosia routes

## ARZ Code Arrangement
- Unique dual-code airport: SCI (main) + ARZ (Terminal D)
- Any airline can operate ARZ-coded flights if ALL passengers ticketed to Areza
- Terminal D has its own Areza customs/immigration (not Balboan)
- Passengers transported to Areza via Line 9 express (non-stop, ~25 min)
- Line 9 built with bypass tracks at all stations for express services

## Metro Connections
- **Line 1**: Airport → Grand Train Terminal (city centre), ~35 min, all stations
- **Line 9**: Airport → Areza via canal corridor, ~25 min express, bypass tracks allow express to skip all local stops

## Cargo
- Major cargo hub (612,000 tonnes/year)
- Reflects position at junction of Illypnian/Fosian/Kaftian markets + canal proximity
- Cargo facilities on eastern side, adjacent to Runway 15/33
