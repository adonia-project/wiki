# Former Countries

Historical polities and nations that no longer exist. Each should have its own folder:

```
Former_Countries/
└── [Country_Name]/
    ├── Laws/
    ├── Regions/
    ├── Events/
    ├── Customs/
    ├── Economy/
    └── .gitkeep
```

## Subfolder Purpose

- **Laws/** - Historical legal documents, acts, constitutions
- **Regions/** - Historical administrative divisions
- **Events/** - Historical events during the country's existence
- **Customs/** - Cultural practices and traditions
- **Economy/** - Historical economic information
