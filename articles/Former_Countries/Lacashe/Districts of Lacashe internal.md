## Naming
- 6 southern/planter-core districts: Burawi names (Guledga CD, Webhose, Dahabga, Dhuldhaxe, Barwaqo, Geeso).
- 8 northern/interior districts: Burawi-orthography renderings of Tapuya-language (Mapudungun-based) toponyms — user directive: "name the more northern districts with Burawi interpretations of native names", "Tapuya language yes!". Waajuri is NOT the indigenous language here — it's an old-world Kaftian language (Ayorin/Dakare).
- Tapuya etymologies: Bikumko (pikum "north" + ko "water"), Mawidaga (mawida "mountain" + -ga), Futalafu (füta "big" + leufü "river"), Bishilemu (pichi "small" + lemu "forest"), Duruful (truful "waterfall"), Kurufa (kürüf "wind"), Antuga (antü "sun" + -ga), Buelko (puel "east" + ko "water").
- Orthographic adaptations: p→b, ü→u, tr→d; Burawi place suffixes -ga/-o. Consistent with the dual name Matarrañya / Cañadapirén (pirén "snow") — Tapuya toponymy already canon.
- Burawi etymologies: Guledga (Guled Badweyn, canon), Webhose (webi "river" + hose "lower" — post-vowel-merger spelling), Barwaqo ("abundance"), Geeso (gees "corner"), Dhuldhaxe (dhul "land" + dhaxe "middle"), Dahabga (dahab "gold" + -ga).
- Dropped from the earlier 14-name Burawi set (replaced by Tapuya names): Dhagaxo, Guryasamo, Badiyo, Cawso, Dhoobo, Weyno, Cadho, Sareyo.
